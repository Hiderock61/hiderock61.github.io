TSUWAMONO LAB / OFFLINE DEMO

一度覚えた操作を、別の対象へ。

写真を選ぶ、分類する、保存する。そんな3つの操作を「技能」に変えて、別の写真に自動実行する仕組みを、架空のデータで試せます。

デモ画面は単体HTML。登録不要・架空データのみ・Chrome拡張不要。

画面は試作品のサンプルです。実サイトを自動操作する製品ではありません。

HOW IT WORKS

試すのは、まず2クリック。

実際の操作結果は、デモ内部の保存データと照合します。単なる動画再生ではありません。

01 / 覚える

お手本の3操作を記録

架空の「ポスター」を選び、分類先「ライブ」を選び、保存する。最初のボタンでサンプル操作を実行し記録します。

02 / 技能化

対象を変えられる手順に

「写真を選ぶ → 分類を選ぶ → 保存」を、次に使える手順として組み立てます。

03 / 再実行

別の写真に自動実行

「街角」を「風景」へ分類して保存。画面の表示だけでなく、デモ内の保存台帳を確認します。

CAPABILITIES & LIMITS

できることと、できないこと。

使える範囲を曖昧にしないために、現時点の機能をそのまま掲載しています。

✅ このデモでできること

  • このHTML内での3操作の記録と手順化
  • 別の架空写真・分類先への自動再実行
  • 保存の成功をデモ内台帳で独立照合
  • 技能JSONの書き出しと読み込み
  • 曖昧な対象や偽の保存成功を検出する試験

⛔ このデモではできないこと

  • 一般のWebサイトやログイン済みページの自動操作
  • パソコン・スマホ全体の操作の記録
  • 時間を決めた無人・定期実行
  • 未知サイトをAIが判断して操作すること
  • 実際の写真ファイルの自動整理

FAQ

よくある質問

「自動実行」は本当にクリックしているの？

はい。このデモではブラウザ上の架空アプリに対して対象ボタン・分類欄・保存ボタンを操作します。ただし、ほかのWebサイトを操作することはできません。

操作内容や写真がネットへ送信される？

この配布候補のデモには外部送信処理を組み込んでいません。架空のサンプルをページ内で操作します。ただし、利用者が編集したHTMLや外部のブラウザ拡張機能の動作までは保証しません。

Chrome拡張やLinuxは必要？

この無料体験版には不要です。開発中のChrome拡張版 v0.4 とは別の製品段階です。

自分の仕事に使ってよい？

この版は架空データ専用の技術デモであり、実務サイトを操作する機能はありません。デモの利用と、コードの改変・再配布は別です。詳しくは利用条件をご確認ください。
