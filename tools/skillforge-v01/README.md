# 技能採集機 v0.1｜ツワモノ第6回
種類: オフライン単体HTML試作アプリ（独立した架空の写真整理画面）
起動: このフォルダの `index.html` をWebブラウザで開く。
用途: 「記録開始」→写真選択→分類選択→保存→「手順をコンパイル」→別写真/分類へ再実行。
確認済み: 過去のChromium Playwright操作試験25/25 PASS（架空画面内に限定）。
未実装: 任意の実Web画面での記録、Chrome拡張、クロスアプリ操作、IrisGo本家相当、Chromebook/iPhone実機。
注意: 同名対象が複数など曖昧な操作はSTOP。保存メッセージだけを成功証拠とみなさない。
