# ⛄ Inquiry Desk 001 / 問い合わせ整理デスク

ヒデロツク本館の既存の仕事相談受付を壊さず、雪だるま法©️で再利用可能な問い合わせQA工程を実演するWebアプリ。

## 入口
- 来訪者の仕事相談フォーム: https://form.jotform.com/262565341165053
- 本館の新設デモ: /inquiry-desk/
- 仕事用ポートフォリオ: /work/

## できること
- 架空6件を検品、緊急1件 / 分類待ち1件 / 本文不足1件 / 正常3件として表示。
- Jotformから持ち主が自分の端末で書き出したCSVを、端末のブラウザ内だけで検査。
- CSV列名「今どうなっていますか？」「どうなれば助かりますか？」「返信先メールアドレス」などを認識する。
- ID/本文欠落、種別/優先度未判定、緊急未完了を INPUT_MISSING / NEEDS_REVIEW / URGENT_REVIEW / OK に分ける。
- 種別、優先度、対応状況は担当者が設定し、CSVをダウンロード。

## 安全設計
- 実データ公開・自動同期ではない。Jotformの実際の投稿内容はGitHubへ含めない。
- GitHub Pagesは静的サイト。認証付きバックエンド・実運用DBではない。
- 既存Jotformの設定は変更しない。
- 相談CSVをネットワークへ送らない。fetch、analytics、外部JS、CDN、LocalStorage、Cookieを使わない。
- CSVはブラウザの再読み込みで消える。共有PCで個人情報を扱わない。
- 返信、契約、公開、最終優先度判断は人間に残す。
