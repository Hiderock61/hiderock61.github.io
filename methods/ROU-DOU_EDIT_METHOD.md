# ROU-DOU編集方法©️ v1.0

> **この方法の芯**：完成稿を作る前に、埋もれた原典を発掘し、地層を壊さず作品世界へ戻す。

## 目的

長期チャットで自然発生した作品世界を、原典を潰さずに発掘・分類・接続し、別ルームでも再現可能な編集工程として運用する。

名称は ROU-DOU だが、刑務所世界観など、長期チャットから作品世界を掘り起こす編集全般へ適用できる。

## 親構造

ROU-DOU編集方法©️は、次の方法©️を組み合わせて使う複合編集方法。

- 親：編集室発掘・作品札化法©️
- 掘削：逆読みGo注釈法©️
- 分岐：坂読み分岐法©️
- 保管：Notionの作品札・現象札・出来事札・時系列背骨
- 実装／履歴：GitHub

## 基本原則

1. **原文優先**
   本人発話、当時の文章、自然発生した設定を正本にする。

2. **要約は後**
   最初に短くまとめない。まず拾う。

3. **地層を残す**
   同じ題材でも、時期・視点・語り方が違えば別層として保存する。

4. **分岐を捨てない**
   本筋から外れた断片は削除せず、坂読み分岐として別枝へ逃がす。

5. **AI補作禁止**
   編集者AIが「それっぽい文章」を足して原典を覆わない。

6. **作品化は最後**
   発掘 → 札化 → 接続 → 整理の後で、必要なものだけ作品へ組み上げる。

## 標準工程

1. 現在地点を固定する。
2. チャットを逆方向へ読む。
3. 重要断片を原文付きで回収する。
4. 断片を現象札・出来事札・作品札などへ昇格する。
5. 別テーマは坂読み分岐として枝分けする。
6. 既存Notion・DB・作品世界へリンクする。
7. 重複を確認し、同一内容なら統合、異なる地層なら併存させる。
8. 時系列背骨やテーマ別棚へ接続する。
9. 発掘が落ち着いた段階でのみ清書・章立て・公開用編集へ進む。

## 判定基準

### 残す

- 本人固有の言葉
- 生活ディテール
- 世界観の発生点
- 後から意味が変わった断片

### 札化する

- 単独で再利用できる出来事
- 概念
- 制度
- 人物関係
- 作品の種

### 分岐する

本筋を止めるほど大きい別テーマ。

### 統合する

内容・時期・意味がほぼ同じ重複。

### 統合しない

同じ題材でも、時期・体感・意味が違うもの。

## 入力

- 現行チャット
- 過去チャット
- 既存Notion
- 原文断片
- 作品札
- 現象札
- 時系列札
- 既存の章・設定・タグ

## 出力

- 原文を保持した発掘結果
- 作品札
- 現象札
- 出来事札
- 分岐枝
- 関連リンク
- 時系列背骨
- 作品世界の更新地図

## NG

- 最初から小説や完成稿にする
- 原文をAI要約で置換する
- 似た断片を一つに潰す
- 時期や視点の違いを無視する
- 埋もれた枝を勝手に捨てる
- AIがそれっぽい設定を補作して原典を覆う

## 呼び出し文

**「ROU-DOU編集方法©️で続けよう」**

と言われたら、この工程を正本として再開する。

### コピペ用プロンプト

> この作品世界を「ROU-DOU編集方法©️ v1.0」で編集してください。原文を正本として保持し、いきなり清書・章立て・要約をせず、逆読みで発掘 → 重要断片を札化 → 坂読み分岐 → 既存Notion/作品札へ接続 → 重複と地層を整理 → 最後に必要な範囲だけ作品化してください。AI補作で原典を覆わないでください。

## 現在の適用例

### 刑務所世界観

- 現象採集庫
- 現象カード
- 時系列背骨
- 原文・既存地層の発掘

へ分けながら、世界観を要約で潰さず回収する。

### ROU-DOU

原典の語感や自然発生した世界観を守り、後付けの「それっぽい行政文」が原典を覆わないよう編集する。
