## 発明種別の判定軸

> **「〇〇でやって」と言われた時、AIがその場で主要処理を開始できるか？**

発明したものを全部「方法©️」と呼ばない。

- **🤖 AI方法©️**：入力を渡せばAIが主要処理を開始できる。
- **🤝 協働方法©️**：AIの処理と、人間側の実機・現実行動の往復で成立する。
- **🔑 OS**：単発処理ではなく、生活や作業全体の置き方を決める運用体系。
- **🧰 プロトコル**：正本・登録・復旧など、仕組みそのものを守る運用規則。
- **🧭 ガイド**：人間側が現実で動くための探索・行動アドバイス。AIは補助役。

## 正本化ルール

新しい発明品が生まれたら、最初に**発明種別**を判定する。

1. AIが主要処理を実行する → **AI方法©️**
2. 人間の実機・現実行動との往復が本体 → **協働方法©️**
3. 生活・作業全体の置き方を決める → **OS**
4. 正本・登録・復旧など仕組みを守る → **プロトコル**
5. 人間が現実で動くための知恵 → **ガイド**

その上で必要に応じ、目的／使う場面／入力／手順／出力／NG／接続関係を記録する。

原典が確認できない発明品を、AIの記憶だけで勝手に正本化しない。

## 運用

`現実で使う → 発明が生まれる → 発明種別を判定 → Notionで正本化 → 必要なものをGitHubで再現可能にする → また使って更新する`

「方法©️見て」「OS見て」「プロトコル見て」「ガイド見て」と言われた時は、記憶から再現せず、NotionまたはGitHub正本を先に確認する。
