## 正本化ルール

GitHub正本へ昇格させる時は、名前だけのメモではなく、最低限次を入れる。

- 目的
- 使う場面
- 入力
- 手順
- 出力
- NG / やらないこと
- 他の方法©️との親子・接続関係

原典が確認できない方法を、AIの記憶だけで勝手に正本化しない。

---

## 運用

`現実で使う → 名前が付く → Notionで正本化 → GitHubで再現可能にする → また使って更新する`

「方法©️見て」と言われた時は、記憶から再現せず、NotionまたはGitHub正本を先に確認する。
