## 2｜それってどうやるの法©️｜現行 v1.0

### 一言
抽象的な答え・判断・発見へ「で、現実にはどうやる？」を当て、必要な専門知だけを選び、次の身体動作または実行可能な手順まで降ろす方法。

### 入力
答え、判断軸、有力案、やりたいこと、詰まっている作業。

### 出力
- NEXT ACTION
- PROCEDURE
- DECISION RULE
- CHECKLIST
- 条件分岐表

### 配役
職業専門家 + 学問専門家 + BONSAI劇団員を、案件に必要な分だけ招聘する。

### 停止条件
説明が詳しくなっただけでは終了しない。利用者が次の動作を実行できる状態まで降りたら止める。

## 3｜それってどう作るの法©️｜現行 v0.1

### 一言
「必要な物が分かった」の先で、カード・画面・テンプレ・Web・仕組み・治具などを実際の試作品まで作る製作法。

### 標準工程
1. 作る物を1文で固定
2. 誰が・どこで・何のために使うか固定
3. 完成状態を「使えた」で定義
4. 必要な専門家だけ招聘
5. 製作仕様札を作る
6. 最小試作
7. 壊し試験
8. YES / NOで検品
9. 実出力

### 配役
- 理論家 / 学問: 何を見るべきか
- 元プロOB席: 現場で何が起きるか
- 職人 / 製作役: 実際にどう作るか
- 現場監督: 順番・依存・引き渡しを統合

### 停止条件
**試作品が実際に存在すること。** 説明書だけで試作品がなければ未完成。

## 4｜雪だるま法©️｜現行 v0.2

### 一言
仕事からAIへ渡せる一工程を実際に動かし、その結果から能力・データ・発見を増やし、本筋を保ちながら次の実行可能領域を広げる方法。

### 原点
**一個動かす → 結果を見る → 次を発見する**

### v0.2運用形
**一個動かす → 結果を見る → 必要なら能力を増やす → 本筋を確認する → 次を動かす**

### 主要工程（2026-10-13｜Plugin装着追補）
作業発見 → 🥷HOWTO動詞分解 → 旧装備復元（049・名簿）→ 🤖自己認識能力照合（047・AKECHI PORT）→ 能力穴検出 → DISCOVER（必要な時だけ）→ 🤩平賀カラクリがPluginのInput→Outputと搬送を配線 → 対象URL/ID・権限監査 → 最小実機 → 結果と失敗を観測 → 証拠付き能力名簿へ帰還 → MAIN / PROBE / SPINOFF / NOISE判定

### 雪だるま法©️と太った君©️
- **雪だるま法©️**＝案件を食べて能力を増やす進め方。旧能力を消さず不足した動詞に必要なPluginだけを装着する。
- **太った君©️**＝その方法で蓄積した専門能力・コード・Plugin配線・証拠・停止条件を束ねた実行体。別AI人格の常駐を意味しない。
- 2026-10-13時点のあだ名は中央9＋追加2（SELF DEMO）＝呼出候補11。実顧客納品数ではない。
- 今回のPlugin最小実証：MiniFish対象403→Exa Searchでは同名別ID→Exa URL Fetchで正しい公開案件本文を取得。商品監視E2Eとは区別。
