CASE 1｜杉並区方南

キッチン蛇口の水漏れ

流れを見る
この案件で実際に行った流れ
  1. 蛇口の先端と根元を確認し、水漏れ箇所を特定。
  2. 内部カートリッジの劣化を確認。
  3. 交換が必要な理由、部品代を含む総額を説明。
  4. 了承後にカートリッジを交換。
  5. 通水して、水漏れが止まったことを一緒に確認。

CASE 2｜杉並区高円寺

洗面台の排水が遅い

流れを見る
この案件で実際に行った流れ
  1. 洗面ボウルへ水を流し、排水速度を確認。
  2. 排水管内部の汚れによる流れの低下と判断。
  3. 清掃範囲と料金を説明。
  4. 了承後に排水管内部を清掃。
  5. 再度水を流し、排水速度が戻ったことを確認。
原因
排水管内部の汚れ
作業

CASE 3｜中野区南台

トイレが流れにくい

流れを見る
この案件で実際に行った流れ
  1. 便器内の水位と流れ方を確認。
  2. 紙類による軽度の詰まりと判断。
  3. 便器を外さない作業で対応できることと料金を説明。
  4. 了承後に専用器具で詰まりを除去。
  5. 複数回流し、正常に排水することを確認。

蛇口から水が漏れる

蛇口の先から漏れる、根元が濡れる、ハンドルを閉めても水が止まらないなどの状態を確認します。

トイレの水が流れない

水位が上がる、流れが戻る、タンクから漏れる、便器まわりの床が濡れるなどの症状を確認します。

排水口の流れが悪い

水が引くのが遅い、逆流する、ゴボゴボ音がする、臭いがするなど、排水の状態を確認します。

蛇口を交換したい

レバーが固い、水栓が古い、交換できる製品を知りたいなど、既存水栓を確認してご案内します。
