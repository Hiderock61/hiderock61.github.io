# AKECHI PORT｜外付け能力図鑑 v2 完全実装指示・制作工程追補

## 工程

1. Notion正本001〜085を読み、先に85件を受け止める1 Pluginカードと全体Navigationを固定する。
2. 「それってどうやって作るの？」製作モードを適用し、利用者・使用場面・単一成果物・制約を固定する。
3. 12の想定故障を先に出し、各故障に対する判定可能な対策を母型へ入れる。
4. 専門家は講演させず、色彩／知覚／情報設計／Web制作／編集／文字組み／Accessibility／ページ順／接続構造／How to／現実圧の観測軸として使う。
5. Whimsicalがなければ停止せず、同じ項目を確認するテキストWireframeを作る。
6. Figma既存試作を観察し、閉じたカードと開いたカードを含む母型へ改善する。
7. 現場監督が、利用者画面に不要な理論・専門家説明・装飾を削除する。
8. Notion由来データから `catalog-v2.json` を生成し、同じデータで静的HTMLを生成する。
9. 85件すべてを10 Genreへ一意に分類し、各カードへ普通の説明／具体例／設計副音声／入力と出力／明智案／接続時の受け渡しを入れる。
10. GitHub Pagesへ公開し、iPhone／Desktop／大画面／初見／情報量／Printの壊し試験を通す。
